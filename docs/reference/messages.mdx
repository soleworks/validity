Every message below is a property of `messages { }`, in [the configuration](/guides/configuration). Change
any of them once, at startup, or for one call. See [Messages](/guides/messages) for placeholders and the
other ways to change them.

## Phone numbers

In `validity-phone`, with the block `messages { phone { … } }`.

| Message | Default | Used by |
|---|---|---|
| `phone` | `must be a valid phone number` | `phone` |
| `mobilePhone` | `must be a valid mobile phone number` | `mobilePhone` |
| `countryCode` | `must be a valid country calling code` | `countryCode` |
| `areaCode` | `must be a valid area code` | `areaCode` |

filled in when a violation is built. The `phone { }` block needs `validity-phone` and the import
`io.github.soleworks.validity.phone.phone`; remove it when you do not use the module.

  this page as Markdown at `/reference/messages.md`.
