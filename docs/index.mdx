## Introduction

Validity is a validation library for Kotlin. You describe the rules of your data in plain Kotlin, next to the data,
and Validity reports every rule that is broken, each with a path, a message for people and a code for programs.

```kotlin User.kt
data class User(
    val name: String?,
    val email: String?,
    val age: Int?
) : Validatable {
    override fun validation() = validation {
        ::name required { minLength(2) }
        ::email required { email() }
        ::age ifPresent { min(18) }
    }
}
```

```kotlin
User(name = "A", email = "ana@", age = 16).validate().violations
```

| Path | Message | Code |
|---|---|---|
| `name` | must have at least 2 characters | `minLength` |
| `email` | must be a valid email | `email` |
| `age` | must be at least 18 | `min` |

## Features

- Plain Kotlin: no annotations, no code generation, no reflection
- Every broken rule at once, with paths into nested objects, lists and maps
- Conditions are ordinary `if` and `when`
- Rules across fields, and rules that depend on the caller
- Rules can call `suspend` functions, such as a database lookup
- {{constraints}} built-in constraints, with documents of {{documentCountries}} countries and postal codes of {{postalCountries}}
- Messages you can translate, and codes that never change
- Depends only on the Kotlin standard library and kotlinx.coroutines
