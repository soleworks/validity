The constraints of `java.time` values, and of `java.util.Date`. `past`, `future` and their `OrPresent` forms read the
[clock of the configuration](/guides/time). The comparisons take a value of the same type.

<NullArguments />

```kotlin Event.kt
data class Event(
    val startsAt: OffsetDateTime?,
    val endsAt: OffsetDateTime?,
    val announcedOn: LocalDate? = null
) : Validatable {
    override fun validation() = validation {
        ::startsAt required { future() }
        ::endsAt required { after(startsAt) }
        ::announcedOn ifPresent { pastOrPresent() }
    }
}
```

| Constraint | Checks |
|---|---|
| [`past`](#past) | Is before now. |
| [`future`](#future) | Is after now. |
| [`pastOrPresent`](#pastorpresent) | Is now or before. |
| [`futureOrPresent`](#futureorpresent) | Is now or after. |
| [`after`](#after) | Is after `other`. |
| [`before`](#before) | Is before `other`. |
| [`afterOrEqual`](#afterorequal) | Is `other` or after. |
| [`beforeOrEqual`](#beforeorequal) | Is `other` or before. |
| [`between`](#between) | Is between `start` and `end`, both included. |
