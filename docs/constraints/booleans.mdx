Two constraints for `Boolean` values, such as the checkbox that accepts the terms. Their messages are `mustBeTrue` and
`mustBeFalse`, since a message property cannot be named `isTrue`.

```kotlin Consent.kt
data class Consent(
    val hasAcceptedTerms: Boolean?,
    val isMinor: Boolean?
) : Validatable {
    override fun validation() = validation {
        ::hasAcceptedTerms required { isTrue() }
        ::isMinor required { isFalse() }
    }
}
```

| Constraint | Checks |
|---|---|
| [`isTrue`](#istrue) | Is `true`. |
| [`isFalse`](#isfalse) | Is `false`. |
