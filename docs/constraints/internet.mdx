Formats of the internet, checked on strings. They check the shape of the value, without network access: `email()` does
not send an email, and `jwt()` does not verify a signature.

```kotlin Webhook.kt
data class Webhook(
    val endpoint: String?,
    val contact: String?,
    val allowedNetworks: List<String>? = null
) : Validatable {
    override fun validation() = validation {
        ::endpoint required { url(schemes = setOf("https")) }
        ::contact required { email() }
        ::allowedNetworks ifPresent { each { cidr() } }
    }
}
```

| Constraint | Checks |
|---|---|
| [`email`](#email) | Is an email address: a local part, `@` and a domain with at least one dot. |
| [`url`](#url) | Is an absolute URL with one of `schemes` and a host. |
| [`hostname`](#hostname) | Is a hostname: labels of letters, digits and dashes, separated by dots, at most 253 characters. |
| [`domain`](#domain) | Is a domain name with at least two labels and a top-level domain of letters or punycode, such as `example.com`. |
| [`port`](#port) | Is a port number, from 0 to 65535. |
| [`ip`](#ip) | Is an IPv4 or an IPv6 address. |
| [`ipv4`](#ipv4) | Is an IPv4 address in dotted decimal, such as `192.168.0.1`, with no leading zeros. |
| [`ipv6`](#ipv6) | Is an IPv6 address, such as `2001:db8::1`, with `::` compression and an embedded IPv4 address accepted. |
| [`cidr`](#cidr) | Is a CIDR block: an IPv4 or IPv6 address, `/` and a prefix length that fits it, such as `10.0.0.0/8`. |
| [`macAddress`](#macaddress) | Is a MAC address: six pairs of hexadecimal digits, separated all by `:` or all by `-`. |
| [`slug`](#slug) | Is a slug: lowercase letters and digits in groups joined by single dashes, such as `hello-world-2`. |
| [`jwt`](#jwt) | Has the format of a JWT: three Base64URL parts separated by dots, the last of which can be empty. |
| [`dataUri`](#datauri) | Is a `data:` URI, such as `data:image/png;base64,iVBORw0KGgo=`. |
| [`mimeType`](#mimetype) | Is a MIME type of a registered top-level type, such as `application/json` or `image/svg+xml`. |

## Addresses

### `email`

`email()` on `String`

Checks that the string is an email address: a local part, `@` and a domain with at least one dot.

Quoted local parts and IP address domains are not accepted.

## Networks

### `ip`

`ip()` on `String`

Checks that the string is an IPv4 or an IPv6 address.

### `ipv4`

`ipv4()` on `String`

Checks that the string is an IPv4 address in dotted decimal, such as `192.168.0.1`, with no leading zeros.

### `ipv6`

`ipv6()` on `String`

Checks that the string is an IPv6 address, such as `2001:db8::1`, with `::` compression and an embedded IPv4 address accepted.

## Web formats

### `slug`

`slug()` on `String`

Checks that the string is a slug: lowercase letters and digits in groups joined by single dashes, such as `hello-world-2`.

### `jwt`

`jwt()` on `String`

Checks that the string has the format of a JWT: three Base64URL parts separated by dots, the last of which can be empty.

Only the format is checked. The signature is not verified.

<ConstraintFacts code="jwt" message="must be a valid JWT" change='jwt = "…"' />

`mimeType()` on `String`

Checks that the string is a MIME type of a registered top-level type, such as `application/json` or `image/svg+xml`.

Parameters, such as `; charset=utf-8`, are not accepted.
