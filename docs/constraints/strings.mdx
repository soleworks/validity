The constraints of a `String` value. Length counts characters as Kotlin does (`String.length`), and the byte rules
count the bytes of an encoding, UTF-8 by default. The rules that compare with text you give take `ignoreCase`, `false`
by default.

<NullArguments />

```kotlin MemberProfile.kt
data class MemberProfile(
    val handle: String?,
    val displayName: String?,
    val password: String?,
    val bio: String? = null
) : Validatable {
    override fun validation() = validation {
        ::handle required {
            lengthBetween(min = 3, max = 30)
            lowercase()
            slug()
        }
        ::displayName required {
            notBlank()
            trimmed()
        }
        ::password required {
            minLength(12)
            containsUppercase()
            containsDigit()
            containsSymbol()
        }
        ::bio ifPresent { maxBytes(500) }
    }
}
```
