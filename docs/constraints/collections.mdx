The constraints of a collection as a whole. The size rules work on any `Collection`, on arrays and on `ByteArray`; the
content rules on `List`, `Set` and arrays. To check every element, use [`each`](/guides/collections-and-maps).

<NullArguments />

```kotlin Playlist.kt
private val BANNED_TAGS = listOf("spam", "nsfw")

data class Playlist(
    val tracks: List<Track>?,
    val tags: Set<String>? = null
) : Validatable {
    override fun validation() = validation {
        ::tracks required {
            sizeBetween(min = 1, max = 200)
            distinctBy { it.id }
        }
        ::tags ifPresent {
            containsNone(BANNED_TAGS)
            each { notBlank() }
        }
    }
}
```

| Constraint | Checks |
|---|---|
| [`minSize`](#minsize) | Has at least `min` elements. |
| [`maxSize`](#maxsize) | Has at most `max` elements. |
| [`size`](#size) | Has exactly `size` elements. |
| [`sizeBetween`](#sizebetween) | Has between `min` and `max` elements, both included. |
| [`notEmpty`](#notempty) | Has at least one element. |
| [`empty`](#empty) | Has no elements. |
| [`contains`](#contains) | Contains `element`. |
| [`notContains`](#notcontains) | Does not contain `element`. |
| [`containsAll`](#containsall) | Contains every one of `elements`. |
| [`containsAny`](#containsany) | Contains at least one of `elements`. |
| [`containsNone`](#containsnone) | Contains none of `elements`. |
| [`distinct`](#distinct) | Has no element twice, by `equals`. |
| [`distinctBy`](#distinctby) | No two elements of the list have the same key, as `selector` picks it. |
