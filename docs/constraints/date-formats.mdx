Text that holds a date or a time, checked without converting it. To validate the date itself, such as "not in the
future", [convert it](/guides/converting-values) with `convertToLocalDate { }` instead.

```kotlin ImportRow.kt
data class ImportRow(
    val createdOn: String?,
    val legacyDate: String? = null,
    val retention: String? = null
) : Validatable {
    override fun validation() = validation {
        ::createdOn required { isoDate() }
        ::legacyDate ifPresent { dateFormat("dd/MM/yyyy") }
        ::retention ifPresent { isoDuration() }
    }
}
```

| Constraint | Checks |
|---|---|
| [`isoDate`](#isodate) | Is an ISO 8601 date, such as `2024-02-29`, that exists in the calendar. |
| [`isoTime`](#isotime) | Is an ISO 8601 time, such as `13:45` or `13:45:30.5`, with no offset. |
| [`isoDateTime`](#isodatetime) | Is an ISO 8601 date and time with an offset, such as `2024-02-29T13:45:30Z` or `2024-02-29T13:45:30+01:00`. |
| [`isoDuration`](#isoduration) | Is an ISO 8601 duration, such as `P1Y2M`, `P3W` or `PT1H30M`. |
| [`dateFormat`](#dateformat) | Is a date or time written exactly in `pattern`. |

## Patterns

### `dateFormat`

`dateFormat(pattern)` on `String`

Checks that the string is a date or time written exactly in `pattern`.

The string is parsed with `DateTimeFormatter.ofPattern` and must print back the same, so `2024-2-9` does not match `yyyy-MM-dd`.
