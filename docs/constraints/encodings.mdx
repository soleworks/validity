Text that encodes something else, checked on strings. They check that the text decodes, not what it decodes to.

```kotlin Attachment.kt
data class Attachment(
    val content: String?,
    val checksum: String?,
    val attributes: String? = null
) : Validatable {
    override fun validation() = validation {
        ::content required { base64() }
        ::checksum required { hash(HashAlgorithm.SHA256) }
        ::attributes ifPresent { json() }
    }
}
```

| Constraint | Checks |
|---|---|
| [`base64`](#base64) | Is Base64 with the standard alphabet and its `=` padding. |
| [`base64Url`](#base64url) | Is Base64 with the URL-safe alphabet (`-` and `_`) and no padding. |
| [`base32`](#base32) | Is Base32 (RFC 4648) in uppercase, with its `=` padding. |
| [`base58`](#base58) | Is not empty and is Base58, the Bitcoin alphabet without `0`, `O`, `I` and `l`. |
| [`hexadecimal`](#hexadecimal) | Is not empty and has only hexadecimal digits, in either case. |
| [`json`](#json) | Is one valid JSON value: an object, an array, a string, a number, `true`, `false` or `null`. |
