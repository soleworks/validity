Documents and numbers of {{documentCountries}} countries, with their check digits. The constraints of each country live in a package of
their own, `io.github.soleworks.validity.constraints.<country>`, and their messages in a block of their own:
`messages { brazil { cpf = "CPF inválido" } }`.

```kotlin Supplier.kt
data class Supplier(
    val country: String?,
    val taxId: String?,
    val zipCode: String? = null
) : Validatable {
    override fun validation() = validation {
        when (country) {
            "BR" -> {
                ::taxId required { cnpj() }
                ::zipCode ifPresent { cep() }
            }

            "ES" -> {
                ::taxId required { nie() }
            }

            "US" -> {
                ::taxId required { ein() }
            }
        }
    }
}
```

## Brazil · `constraints.brazil`

For `cpf`, `cnh` and `pis`, a number with all its digits the same, such as `111.111.111-11`, fails.

### `cpf`

`cpf()` on `String`

Checks that the string is a Brazilian CPF with valid check digits, as 11 digits or as `000.000.000-00`.

<ConstraintFacts code="cpf" message="must be a valid CPF" change='brazil { cpf = "…" }' />

### `cnpj`

`cnpj()` on `String`

Checks that the string is a Brazilian CNPJ with valid check digits, as 14 characters or as `00.000.000/0000-00`.

The first 12 characters can be uppercase letters, as in the alphanumeric CNPJ.

<ConstraintFacts code="cnpj" message="must be a valid CNPJ" change='brazil { cnpj = "…" }' />
