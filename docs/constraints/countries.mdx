Documents and numbers of {{documentCountries}} countries, with their check digits. The constraints of each country live in a package of
their own, `io.github.soleworks.validity.constraints.<country>`, and their messages in a block of their own:
`messages { brazil { cpf = "CPF inválido" } }`.

```kotlin Supplier.kt
data class Supplier(
    val country: String?,
    val taxId: String?,
    val zipCode: String? = null
) : Validatable {
    override fun validation() = validation {
        when (country) {
            "BR" -> {
                ::taxId required { cnpj() }
                ::zipCode ifPresent { cep() }
            }

            "ES" -> {
                ::taxId required { nie() }
            }

            "US" -> {
                ::taxId required { ein() }
            }
        }
    }
}
```

## Any country · `taxId`

### `taxId`

`taxId(type)` or `taxId(country, type)` on `String`

Checks that the string is a document of `type`, with the same rules as the constraint of that document on this page.
`type` is a `TaxIdType`, one entry per document named after its country and its type, such as `TaxIdType.AR_CUIT`.
When the country and the type come as text, such as from a request, `country` is an ISO 3166-1 alpha-2 code and
`type` the name of the constraint in upper snake case, such as `CUIT` or `PARTITA_IVA`, both in any case.

When `type` is `null`, or the pair of `country` and `type` is not known, nothing is checked.

<ConstraintFacts code="taxId" message="must be a valid {type} for {country}" change='taxId = "…"' />
