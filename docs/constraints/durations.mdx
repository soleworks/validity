The range constraints of lengths of time, for both `kotlin.time.Duration`, with arguments such as `15.minutes`,
and `java.time.Duration`, with arguments such as `Duration.ofDays(1)`.

<NullArguments />

```kotlin Meeting.kt
data class Meeting(
    val length: Duration?,
    val reminderBefore: java.time.Duration?
) : Validatable {
    override fun validation() = validation {
        ::length required { between(min = 15.minutes, max = 4.hours) }
        ::reminderBefore required { max(java.time.Duration.ofDays(1)) }
    }
}
```
