The constraints of a `Map` as a whole. Their size messages count entries, not items, so they have messages of their
own (`minEntries`, `maxEntries`, `entries`, `entriesBetween`). To check every key or value, use
[`eachKey` and `eachValue`](/guides/collections-and-maps#maps).

<NullArguments />

```kotlin Translations.kt
private val LANGUAGES = setOf("en", "pt", "es")

data class Translations(
    val titles: Map<String, String>?
) : Validatable {
    override fun validation() = validation {
        ::titles required {
            containsKey("en")
            onlyKeys(LANGUAGES)
            eachValue { maxLength(80) }
        }
    }
}
```

| Constraint | Checks |
|---|---|
| [`minSize`](#minsize) | Has at least `min` entries. |
| [`maxSize`](#maxsize) | Has at most `max` entries. |
| [`size`](#size) | Has exactly `size` entries. |
| [`sizeBetween`](#sizebetween) | Has between `min` and `max` entries, both included. |
| [`notEmpty`](#notempty) | Has at least one entry. |
| [`empty`](#empty) | Has no entries. |
| [`containsKey`](#containskey) | Has the key `key`. |
| [`containsKeys`](#containskeys) | Has every one of `keys`. |
| [`notContainsKey`](#notcontainskey) | Does not have the key `key`. |
| [`onlyKeys`](#onlykeys) | Every key of the map is one of `keys`. |
| [`containsValue`](#containsvalue) | Has `value` as the value of some entry. |
