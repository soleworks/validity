Rules about the calendar. `minAge`, `maxAge`, `today`, `withinNext` and `withinLast` read the
[clock of the configuration](/guides/time), so tests can fix it. The windows take a `kotlin.time.Duration`, such as
`30.days`.

<NullArguments />

```kotlin Appointment.kt
data class Appointment(
    val date: LocalDate?,
    val patientBirthDate: LocalDate?
) : Validatable {
    override fun validation() = validation {
        ::date required {
            weekday()
            withinNext(60.days)
        }
        ::patientBirthDate required { maxAge(120) }
    }
}
```

| Constraint | Checks |
|---|---|
| [`minAge`](#minage) | Someone born on the date is at least `min` years old today. |
| [`maxAge`](#maxage) | Someone born on the date is at most `max` years old today. |
| [`today`](#today) | Falls on today. |
| [`withinNext`](#withinnext) | Is between today and `duration` from today, both included. |
| [`withinLast`](#withinlast) | Is between `duration` before today and today, both included. |
| [`weekday`](#weekday) | Falls from Monday to Friday. |
| [`weekend`](#weekend) | Falls on a Saturday or a Sunday. |

## Around now

### `today`

`today()` on `LocalDate`, `LocalDateTime`, `ZonedDateTime`, `OffsetDateTime`

Checks that the date falls on today.

 It is moved to the zone of the clock before its date is compared.

### `withinNext`

`withinNext(duration)` on `LocalDate`, `LocalDateTime`, `ZonedDateTime`, `OffsetDateTime`, `Instant`
