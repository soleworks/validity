<Warning>
  Validity is not on Maven Central yet: the first release is on its way. Until it lands, clone the
  [repository](https://github.com/soleworks/validity) next to your project and add `includeBuild("../validity")` to
  your `settings.gradle.kts`. Gradle then builds the dependency from the clone, so the dependency names no version.
  Maven cannot build from a clone, so a Maven project waits for the release.
</Warning>
